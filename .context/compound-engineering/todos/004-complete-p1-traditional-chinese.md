# 繁体中文迁移与来源校对

## Problem Statement
简体界面和机器译文未贴合游戏的繁体中文用词。

## Findings
现有五套资料含 133,802 个中文字段位置，42,785 段不同英文文本。
Fandom 繁体 Wiki 为译名首选。灰机 Wiki 补充缺漏和别名。
英文固定修订继续提供游戏事实。

## Proposed Solutions
沿用现有语言投影，将中文运行语言替换为 zh-TW。
采集中文证据，重译无中文来源的文本，保持审校状态透明。

## Recommended Action
执行用户已批准的计划。用户后续授权全部修复、发布新版本并部署 ZimaBoard。

## Acceptance Criteria
- [x] 中文证据、术语及可续跑的校译输入就绪。
- [x] 默认繁体、旧偏好迁移和原生界面完成。
- [x] 五套繁体资料、来源状态、名称别名及繁体查询完成。
- [x] Web 和桌面离线路径及旧资源恢复完成。
- [x] 数据校验、测试、浏览器和构建验证完成。
- [x] 文档与实际限制完成记录。
