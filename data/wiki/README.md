# Guild Wars Wiki revision evidence

These are read-only snapshots used to verify MappingOut's game content. Each page records its title, page and revision IDs, revision timestamp, source URL, permanent revision URL, retrieval timestamp, and original wikitext. Original contributors are credited through the page history at `https://wiki.guildwars.com/index.php?title=<URL-encoded title>&action=history`; the application links both the fixed revision and its history.

Wiki original contributions are available under GNU Free Documentation License 1.3 or later. The license text is bundled at `public/licenses/gfdl-1.3.txt`. ArenaNet game content retains its original rights and is not relicensed by inclusion in a Wiki snapshot. See the saved `Guild Wars Wiki:Copyrights` page and <https://wiki.guildwars.com/wiki/Guild_Wars_Wiki:Copyrights>.

Candidate matching, image comparisons, and downloaded pages are research evidence. Only entries included in the compiled corrections are applied to the app; a snapshot alone does not establish that a match or coordinate is confirmed. See `docs/wiki-data-review.md` and the generated public review report for current coverage and remaining work.

`material-icons.json` pins the item page, item-infobox rule and file-page revision for each crafting material. PNG files in `public/assets/materials/` are unchanged originals with matching source SHA-1 and local SHA-256. File pages declare `arenanet image|item icon`; these game images retain ArenaNet / NCSOFT rights. They are distinct from the GFDL profession artwork documented in `profession-icons.json`.

`skill-library-discovery.json` records the current learnable-player-skill discovery scope and directory checks. `skill-library-coverage.json` records every inclusion and exclusion, growth-template revisions, and five description/progression disagreements. The compiled library contains 1,319 skills and 1,503 versions; uncertain values remain visible as source ranges and are excluded from numeric search. See `docs/skills.md` for the exact search and growth rules.

`skill-library-images.json` pins the original 1,503 skill JPGs and seven resource PNGs, file-page revisions, upload timestamps, source SHA-1 and local SHA-256. Files are not re-encoded. The current Debilitating Shot and Equinox downloads disagree with Wiki metadata; each uses its newest verifiable archived upload and records the rejected current URL and hashes in `fallbackFrom`. The Soul Ignition file page has no license declaration; its declaration remains empty and does not establish a GFDL license. ArenaNet game imagery retains its original rights.
