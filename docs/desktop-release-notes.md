MappingOut Desktop 1.3.0：新增离线任务攻略、全职业技能百科和自动更新。

- 任务攻略覆盖四篇章主线、科瑞他战争、变换之风及其他常驻 PvE 任务，共 1,370 项。支持前置关系、奖励、路线图、双语检索和按角色记录进度。
- 职业技能收录 1,319 项技能、1,503 个 PvE／PvP 版本。支持布尔表达式、职业多选、资源范围、属性等级和同一效果分项内的数值比较，引用 Wiki 原始技能与消耗、施放、冷却、怒气图标。
- 修复科学计数值范围输入、效果分组跨项匹配、固定负护甲数值，以及技能获取任务沿用旧困难模式的问题。
- 全部下拉菜单使用统一主题；地图导航改为“世界地图 → 章节 → 地图”；职业图例默认收起，展开为左上角两行五列浮框。护甲制作增加职业和材料图标。
- 启动后自动检查、下载并验证程序更新；就绪后可立即重启或下次打开时安装。安装前等待个人记录保存并生成备份；下载完成的延期包支持离线安装。
- 地图、资料和字体使用独立签名资源包。首次使用下载或导入资源，准备完成后离线使用；后续更新复用内容未变的资源包。

个人记录和备份升级为 v3，接受 v1／v2 备份。数据库名称、应用标识与更新公钥不变。升级前建议导出个人备份；回退代码须保留 v3 存储兼容层。

本版本按用户 2026-11-17 的明确发布要求发布，资料校订尚未完成：131,779 个中文字段位置待人工复核，2,026 个英文字段待确认 Wiki 来源，1,988 个中文字段有数值／标记待核对项，14,086 个中文字段含未译拉丁词。统计包含重复位置，待核对不等于已确认错误。任务攻略仍有 163 项详细攻略来源缺口和 5 个图源缺口；五处技能正文与成长表冲突保留说明，争议数值不参与筛选。

- Windows x86（32 位）与 x64：安装包复用 WebView2；缺失时由内置引导器联网安装。完全离线安装需另备对应架构的 WebView2 安装器及三个资源 ZIP。
- macOS arm64：Apple Silicon，macOS 11 或更新版本；初次安装使用 DMG，app.tar.gz 与 .sig 用于程序更新。
- 完全离线导入：将 resources.json 与其列出的三个 ZIP 放在同一目录，在首次准备界面选择“导入离线资源”。
- 个人记录保存在本机，支持 JSON 备份、自动备份与恢复前备份。语言偏好不写入个人备份。

Windows 尚无 Authenticode 发布者证书；macOS 使用 ad-hoc 签名，尚无 Apple Developer ID 签名或公证。程序更新和资源使用独立签名，不能替代系统发布者签名。
