# 应用图标：赤晶探索印记

设计采用古铜罗盘、赤红切面水晶和深青石色底板，呼应《激战》初代的奇幻冒险、旧地图与金属装备气质。保留独立的 MappingOut 探索工具辨识，不直接使用游戏官方标志。无文字设计以适配小尺寸任务栏和 Dock。

源文件：`desktop/icons/icon-source.svg`。1024px 预览：`desktop/icons/icon-master.png`。运行 `node scripts/desktop/desktop-icon.mjs` 可重新生成 PNG、Windows 多尺寸 ICO 及 macOS ICNS。

ICO 包含 16、24、32、48、64、128、256px；ICNS 包含 128、256、512、1024px。图标外围保留真实透明区域。

本设计直接编辑现有矢量图标系统，未使用 AI 位图生成。安装包会在下次构建时包含新图标，已发布的历史安装包不变。
