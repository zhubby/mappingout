# 自定义下拉菜单

语言、地图章节、地图地区、探索筛选、护甲筛选、制作方案、日历时区和活动类别共 16 处单选控件，统一使用 `src/shared/ui/Select.tsx`。资源准备页也使用同一菜单。界面不再渲染原生 `select`、`option` 或 `optgroup`。

菜单沿用应用的深绿背景、金色边框和双语字体。已选项显示勾选标记。浮层挂载到文档根部，以避开地图和滚动容器裁切；视口空间不足时向上展开。手机选项至少高 44 像素。

地图导航使用“世界地图 › 章节选择 › 地图名称”三级结构。切换章节后显示该章节的首张地图。地图菜单只列出当前章节的地图。章节值直接取自当前地图，分享链接、重新加载与地点定位均保持同步。地图导航独立于左侧资料筛选。窄视口保留三级导航，笔记按钮空间不足时换行。

地图左侧以搜索框开头，随后为资料类别、筛选项与结果列表。桌面和手机查询页共用此布局。

## 操作

- 点击或触摸打开菜单，选择后关闭并返回触发器。
- 方向键移动高亮，Home 和 End 定位首项与末项。
- Enter 或空格确认选项；输入文字按选项前缀定位。
- Escape 取消，保留原值；Tab 关闭菜单并继续焦点顺序。
- 点击菜单外部关闭；触摸滚动不会提交选项。

触发器使用 `combobox`，菜单使用 `listbox`，选项使用 `option`。高亮通过 `aria-activedescendant` 传达，已选状态通过 `aria-selected` 传达。触发器保留各业务控件的无障碍名称。

筛选重置、URL、护甲材料计算、日历时区偏好和个人数据仍由业务视图维护。Select 只接收值和选项，并在用户确认后通知调用方。桌面更新提示在菜单保持焦点时等待，避免打断选择。

## 验证

```sh
npm test
npm run build
npm run test:e2e
npm run test:e2e:updates
```

浏览器回归覆盖三级地图导航、章节与地图联动、分享链接、地点定位、筛选联动、空值、键盘、前缀定位、取消、焦点、手机触摸和双语 320–1440 像素视口。原有护甲、日历和双语回归改为选择真实菜单选项。桌面回归覆盖资源准备页的语言菜单，以及菜单聚焦时暂缓更新提示。

2026-11-16，自定义菜单改造验证：141 项单测、4 项菜单回归、10 项桌面回归及 Web 生产构建通过。完整 Web 回归为 26/28；两项失败仍是 `area review separates missions, dungeons and genuine vanquishing targets` 与 `treasure dates, vanquishing, filters and layer switches persist` 的保存后立即刷新断言。两项此前均在独立基线快照复现，证据见 [更新验收中的已有失败](../verification/desktop-updates-verification.md)。
