# 客戶端語言與離線字體

繁體中文（`zh-TW`，預設）與 English 使用獨立字典和資料包。
舊 `zh-CN`、缺失或無效的裝置偏好會遷移並保存為 `zh-TW`。
已保存的 English 偏好保持不變。儲存不可用時仍能啟動和切換。
`mappingout.locale` 不寫入個人備份。角色、筆記及自訂計畫名稱保持原文。

英文事實以固定修訂的 Guild Wars Wiki 為基準。
`public/data/{catalog,armor,calendar,quests,skills}.json` 保持原始事實與身份。
繁體包只投影顯示欄位。ID、座標、逐級數值、配方、輪換週期和 v3 備份不變。
資料包同時綁定原始資料、英文正文及英文來源基準的 SHA-256。
資料缺失或綁定過期時顯示重試入口。

## 中文來源與審校邊界

Fandom 繁體 Wiki 為譯名首選，灰機 Wiki 補充缺漏與別名。
採用「極地之眼」「神喚使」「暗殺者」「弓術精通」等詞。
`data/i18n/chinese-sources.json` 固定 Fandom 正文、模板、修訂、雜湊及授權入口。
`huiji-sources.json` 保存瀏覽器可見表格的名稱和技能編號摘錄。
灰機 API 返回 403，摘錄不冒充原始 wikitext，也不導入中文數值或機制。
`zh-TW-terms.json` 記錄英文身份、首選譯名、別名與引用。
同等證據出現不同譯名時保留衝突，不自動擇一。
`zh-TW-editorial.json` 記錄應用用詞與編輯取捨，並非遊戲內截圖或人工批准。

缺少中文佐證的正文從現有英文重新翻譯為繁體初稿。
維護工具保護固定術語、數字與成長佔位符。
線上服務限流時，可匯出輸入至 Argos OPUS-MT en_zh 1.9 本地模型。
本地模型仍從英文輸入，OpenCC 只將輸出轉為繁體。
本地稿含未知詞元時拒絕寫入；本次最終稿已重新使用線上翻譯。
採用本地稿時，模型來源、授權與 SHA-256 記錄在快取。
模型及維護環境不隨應用分發。
`zh-TW-translations.json` 按英文雜湊保存初稿，支援限流退避和斷點續跑。
已核對英文的技能譯文保留語義修正，再作繁體適配。
旅者交換數量直接由既有英文事實呈現。
這些步驟均不繼承舊簡體的人工復核。

`zh-TW-provenance.json` 綁定每套資料包及每段譯文的來源類型、雜湊和引用。
介面區分「譯名有中文 Wiki 佐證」「無中文佐證的重譯」及「英文來源仍待核實」。
譯名獲佐證不表示正文經中文 Wiki 核對。
任務和技能保留英文原文切換，其他資料保留來源原文。
名稱與正文仍須逐條校訂，機器初稿不算人工審校。

舊簡體名稱、地點和屬性保存在 `legacy-search-aliases.json`。
編譯時同時產生這些舊名稱的繁體別名。
執行時只分發繁體與英文包，兩種視圖均可搜尋舊名稱。
進階技能查詢接受繁體、舊簡體與英文欄位、職業、篇章、屬性和效果。
例：`職業:神喚使 屬性:鐮刀精通 章節:極地之眼 傷害>=20`。
穩定英文篩選 ID 與舊分享連結繼續有效。

## 維護與離線

- `npm run i18n:fetch:chinese`：採集並固定中文來源，預設代理 `127.0.0.1:7890`。
- `npm run i18n:translate:traditional`：從英文生成繁體初稿，僅維護時聯網。
- `npm run i18n:translate:traditional -- --repair`：重譯本地稿及含詞元、數值疑點的稿件。
- `npm run i18n:translate:traditional -- --repair-terms`：重譯含換行標記或媒體名稱污染的快取。
- `node scripts/i18n/translate-traditional.mjs --export-local FILE`：匯出本地待譯輸入。
  以獨立維護環境執行 `python scripts/i18n/local-traditional.py --input FILE --model MODEL_DIR`。
  需安裝 `ctranslate2`、`sentencepiece` 和 `opencc-python-reimplemented`；模型採用 CC-BY 4.0。
- `npm run i18n:compile`：離線編譯五套資料和來源記錄。
- `npm run i18n:compile:ui`：讀取完成的資料包，以實際屬性和稱號名稱生成查詢別名，再生成繁體介面字典。
- `npm run i18n:audit`：對照英文固定快照核對事實。
- `npm run validate:i18n`：檢查欄位、雜湊、中文證據、標記污染、來源記錄及字體檔案。
- `node scripts/i18n/review-report.mjs`：生成合併相同譯文的待審清單。
- `npm run check:release`：執行正式門禁；例外只適用於記錄的版本、資料指紋和待審項目。

OpenCC 只在維護期執行。應用不在線翻譯，不將個人資料送往翻譯服務。
Web Worker 讀取連續 30 秒無進展時中止，單檔最多五分鐘。
已訪問快取和手動完整離線清單只列 `zh-TW` 與 `en`。
桌面啟動要求五套原始資料及繁英資料齊全。
舊簡體資源可驗簽，但不可成為本版執行會話，會進入資源準備。
混合版本頻道可保留舊資源，選擇本版資源時會檢查繁體完整性。
舊版已安裝程式的更新預檢不會自動獲得本次檢查邏輯。
1.4.0 發布的繁體資源限定 `>=1.4.0, <2.0.0`。
舊客戶端依既有版本篩選跳過新資源，仍可選擇頻道內的舊包。
新客戶端檢查全部繁英資料後才啟動。
資源公鑰和頻道保持原值。

## 字体与发布门槛

`FrizQuadrataStd`，包含 Regular、Bold、Italic、Bold Italic。文件未经转换或改名伪装，
SHA-256 固定在清单中；版权与来源说明保存在 `fonts/friz/NOTICE.txt`。
