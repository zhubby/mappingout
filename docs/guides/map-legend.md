# 地图职业图例

职业图例在所有屏幕尺寸下默认收起。图标按钮位于地图左上角，替换“原始地图 · 地标已核对”的提示。未确认地图仍显示原有警告。

点击按钮展开悬浮框。十个职业按两行五列排列，使用现有职业图标、颜色和双语名称。浮框跟随地图可用宽度收窄，不占据地图下方的固定区域。

再次点击按钮、点击外部或移出键盘焦点时收起。按 Escape 收起并将焦点返回按钮。切换地图或隐藏技能图层后重置为收起状态。添加笔记时隐藏图例，避免阻挡地图点击。

职业图例不写入个人记录。职业标记、地图定位与本地图标离线缓存沿用原有规则。

## 验证

浏览器回归核对十职业标记归属、默认收起、图标位置、键盘收起、触摸开关、点击外部、技能图层切换与离线刷新。中英文浮框在 320、390、820、1440 像素视口均核对两行五列与地图边界。

2026-11-16：Web 生产构建与 13 项相关浏览器回归通过。其中 2 项职业图例回归覆盖标记与离线、触摸与双语布局；其余 11 项覆盖三级地图导航、自定义菜单、定位与双语缩放。桌面及手机截图已核对。本次验证使用本地生产构建。
