# 任务攻略

顶部“任务攻略”收录四章、科瑞他战争、北方之心、变换之风和通用 PvE。
按篇章、普通／困难、类型、地区和角色状态筛选。
任务名、领取 NPC 和地点均支持中英文搜索。
目录与攻略并列；手机可以收起目录。
宽奖励表在手机内横向滚动，保留文字列宽。
全部下拉共用 `Select`。

## 范围与来源

从 Guild Wars Wiki 递归分类、区域任务目录和剧情目录发现 1,621 个独立页面。
收录 1,370 项；明确排除 251 项节庆、PvP、历史内容或说明页面。
覆盖报告保存在 `data/wiki/quest-coverage.json`。
“完整”指固定采集范围的收录，不代表 Wiki 未来新增内容已被包含。

地城、精英区域、挑战、职业任务和常驻 PvE 悬赏也在目录内。
清剿读取探索区域攻略，不能复用同名主线副本攻略。

攻略保留领取条件、目标、奖励、流程、额外目标、困难注意事项和来源修订。
精英区和独立玩法指南按来源补充。
1,206 项有详细攻略，39 项保留 NPC 操作指示，125 项补入目标区域注意事项。
其中 163 项非机制任务的 Wiki 来源未单列详细攻略。
界面明确提示这些来源缺口；不把任务目标标成完整攻略。

原始 Wiki 文本固定在 `data/wiki/pages/`，以 pageid 命名。
编译器输出安全内容块；前端不执行 Wiki 模板或 HTML。
奖励表的金币、白金、技能点图标转换为文字单位。
正文移除 gallery 标记，路线图另行收录。
主线信息框的默认地图规则绑定 `Template:Mission infobox` 修订。

1,133 张已引用路线图保存在 `public/assets/quests/`。
每幅图保留文件页修订、原图 SHA-1、WebP SHA-256、许可声明和转换方式。
输出尺寸不超过 1600 × 1600，保留比例，不放大小图。
正文可以放大路线图，并查看固定文件来源。
来源声明为空时保留空值，不推定图像获得 GFDL 许可。
图片缺失或原图校验失败时不收录，界面显示提示。
本次仍有 5 个图源缺口：Hero Tutorial、Trade Relations、Undead Defenders 缺文件。
In the Army (Luxon) 和 Pledge of the Merchant Princes 的下载字节与 Wiki SHA-1 不符。
重复读取和绕过缓存读取仍不一致，保留排除记录。

中文攻略是机器辅助初稿，尚待逐条校订。
界面提示译文状态，并提供英文原文切换。
译文缓存绑定英文哈希；没有补写人工审校记录。
正式发布仍遵守现有翻译、字体及资料门禁。
新资料使旧发布例外的指纹失效，不能自动沿用。

## 角色记录与导航

出生章节、主职业和手动领取条件按角色保存。
前置表达式区分“全部满足”“任一满足”和人工确认条件。
未确认条件显示“条件待确认”，不推测游戏日志。
目录顺序只用于推荐阅读；不能把相邻任务强制变成前置。
编译校验拒绝前置循环和不存在的任务。

普通、困难完成记录分别保存。
额外奖励可以在主任务完成前记录。
大师级奖励记录标准／专家／大师等级。
重复任务再次开始时保留既往通关记录。
删除角色会清除该角色的任务进度及条件。

任务链接可以跳到前置、后续或相关攻略。
已核验区域可以返回地图档案；不新绘制未经核验的坐标。
剧情指南提供各章主线入口。
日历和攻略互相跳转。
本轮悬赏复用日历记录；永久任务完成使用独立记录。
每日重置不会抹掉永久完成状态。

链接保存 `quest`、`qChapter`、`qMode`、`qKind`、`qStatus`、`qRegion` 和 `qq`。
全篇章使用 `qChapter=all`。
地区参数使用英文来源身份，显示名称随界面语言切换。
角色及完成状态仍保存在本地，不写入链接。

## 备份、离线与回滚

IndexedDB `mappingout` 升级至 v3。
v1/v2 在升级事务内保留原记录，初始化空任务记录和条件。
所有变更仍通过原有事务与重启屏障。
导出备份为 `mappingout-backup` v3；继续接受 v1/v2 导入。
校验拒绝孤立角色、重复任务难度、非法时间及非法条件。
恢复操作整体替换数据，失败不替换原记录。

回滚代码必须保留数据库和备份 v3 兼容层。
旧版 v1/v2 程序不能直接打开升级后的数据库。
先导出备份，不通过清理网站数据回滚。
桌面自动更新在备份成功后才安装，备份包含任务进度及条件。

首次安装只缓存启动入口依赖。
全量离线准备包含任务代码、资料、双语包和本地路线图。
全量准备成功后，未单独访问的任务和路线图也可离线阅读。
攻略页独立懒加载，不阻塞其他标签页。
桌面将任务资料、双语包和路线图放入签名资源。
当前另包含第五套职业技能资料，详见 [职业技能](skills.md)。
旧版资源缺少任务资料时，提示更新或导入；地图及其他标签仍可用。
任务资料一旦出现，原生校验要求英文、中文包一同存在。

## 维护与验证

普通构建只读取已保存的来源和译文，不访问 Wiki 或翻译服务。
更新时按以下顺序执行；网络命令可设置 `WIKI_PROXY=http://127.0.0.1:7890`。

```sh
npm run wiki:fetch:quests
npm run wiki:compile:quests
node scripts/wiki/fetch/fetch-quest-expansions.mjs
npm run wiki:compile:quests
npm run wiki:images:quests
npm run wiki:compile:quests
npm run wiki:translate:quests
npm run i18n:compile
node scripts/wiki/audit/audit-references.mjs
npm run build
npm test
npx playwright test e2e/quests.spec.ts
npm run test:e2e:updates
```

刷新已有修订时使用通用采集入口的 `--refresh`，随后重建模板展开、任务和双语包。
来源存在缺图时，图像命令报告失败并保留成功文件。
校验通过只能证明本地已收录数据一致，不能证明缺图已补齐。

验收截图为生产 Web 构建的桌面与手机界面。
桌面更新测试使用测试 IPC，不能替代系统安装器验收。
