# 职业技能百科与高级检索

“职业技能”标签收录十职业、通用、称号及周年可学习技能。
目录、全文、成长数值、图标和获取途径均可离线使用。
技能百科只读，不增加角色技能解锁或 Build 记录。
个人数据库和备份保持 v3。

另有 379 页明确排除，包含怪物、NPC、历史及临时替换技能。

每个版本引用自身页面的固定修订及贡献历史。
成长模板和文件页也保存原始修订。
前端只读取编译数据，不执行 Wiki HTML 或模板。

## 检索规则

名称、正文、注意事项和获取途径支持中英文全文搜索。
名称命中优先于正文提及。
高级面板提供职业、属性、章节、类型、标签和资源范围。
同一分面的多选按“任一”匹配，不同分面同时生效。
全部下拉共用主题 `Select`，支持键盘及手机触摸。

空格和 `AND` 表示同时满足，`OR` 表示任一满足。
`NOT` 或前置 `-` 表示排除，括号改变优先级。
双引号将多词文本视为一个短语。
语法错误标出字符位置，保留上次有效查询结果。

| 示例 | 含义 |
| --- | --- |
| `名称:"Healing Signet" 治疗>=150` | 名称包含该短语，当前等级治疗至少 150 |
| `版本:PvP 能量<=5 冷却<=10` | 同一 PvP 版本符合两项资源条件 |
| `职业:战士 OR 职业:游侠` | 任一职业 |
| `(标签:打断 OR 标签:击倒) NOT 精英:是` | 带指定标签的非精英技能 |
| `效果:(指标:伤害 数值>=50 数值<=80)` | 同一伤害效果分项落在 50–80 |
| `效果:(指标:治疗 方式:每秒 条件:否)` | 不附条件的每秒治疗分项 |
| `名称:Empathy 正文:"attacks"` | 名称与正文同时匹配 |

字段同时接受英文，例如 `profession`、`mode`、`energy`、`recharge`、
`effect`、`metric`、`value`、`scope`、`conditional`。
资源包括能量、怒气、施放、冷却、维持、生命牺牲和过载。
数值比较支持 `=`、`!=`、`>`、`>=`、`<`、`<=`。
资源范围和查询均接受有限科学计数值，例如 `energy>=1e-7`。
毫秒后缀 `ms` 换算成秒；百分比按界面显示值比较。
动态和未知资源值保持未知；`NOT` 也不会将其变成零。

每个查询只在一个版本内匹配，不能拼接 PvE 和 PvP 数值。
`效果:(...)` 内的条件必须由同一效果分项满足。
分组内的 `伤害>=50 伤害<=80` 简写同样绑定当前分项。
多个独立的 `伤害`、`治疗` 条件可以命中不同分项。
需要数值上下界来自同一分项时，使用上述 `效果:(...)` 写法。
“仅无条件效果”排除带条件的数值分项。
默认包括条件效果，并显示条件及每秒、每次命中或每次触发。

属性默认 12，支持 0–20，并允许每个属性独立覆盖。
称号等级分别设置，默认合法最高等级：
阵营称号 12、日戟 10、光明使者 8，其他四个声望称号各 10。
数值按固定成长模板逐级编译。
固定效果保留正负号；`-40 armor` 编译为护甲惩罚 `-40`。
封顶、明表和先取整再乘的成长规则分别保留。
不能按模板名称推定线性增长或封顶等级。

五处 Wiki 正文和成长表存在冲突：

| 技能版本 | 争议分项 |
| --- | --- |
| `"Brace Yourself!" (PvP)` | 伤害 |
| `Comfort Animal` | 治疗 |
| `Disenchantment (PvP)` | 持续时间 |
| `Pacifism` | 持续时间 |
| `Signet of Return (PvP)` | 生命百分比 |

这些说明保留原始范围，详情提示冲突。
争议值不参与数值筛选，不能猜测或用零替代。
其他已核验效果仍可搜索。

## 阅读、链接与图标

详情提供 PvE／PvP 对照、成长表、原文、相关技能和获取来源。
单版阅读跟随当前匹配版本，避免沿用已被筛选排除的版本。
对照模式主动显示该技能的全部版本。
手机可以收起目录，直接阅读详情。
结果每批显示 100 项，后续按需展开。

复制技能链接保留查询、筛选、选中技能、版本和等级。
主要参数为 `sq`、`skill`、`sVersion`、`sCompare`、`sMode`、
`sProfession`、`sAttribute`、`sCampaign`、`sType`、`sTag`、
`sElite`、`sUnconditional`、`sSort`、`sRank`、`sRanks` 和 `sAttributes`。
多选身份以 `|` 分隔；独立等级使用 JSON 对象。
资源范围使用 `senergyMin`、`senergyMax` 等同规则参数。
等级参数会限制到合法范围。
相关技能跳转清除不适用的筛选，保留等级上下文。
获取任务跳转清除旧难度，按目标任务确定普通或困难模式。
链接不包含角色记录。

1,503 张技能 JPG 和七张资源 PNG 保存 Wiki 原始字节。
资源图标保留 20 × 20，不重新绘制或编码。
文件来源、上传时间、SHA-1 和 SHA-256 保存在
`data/wiki/skill-library-images.json`。
Debilitating Shot 和 Equinox 的当前下载字节与 Wiki 元数据不符，
因此使用各自最新可验证的归档上传；清单记录原始差异。
Soul Ignition 文件页无许可声明，保留空值，不推定 GFDL 许可。
游戏图像继续保留原权利归属。

中文技能包含机器辅助初稿，尚待逐条校订。
页面提供英文原文切换及状态说明。
13,492 条独立译文绑定英文哈希，保存在
`data/i18n/skill-translations.json`。
翻译只覆盖文字，不改变资源、等级值、版本、来源或导航身份。
数字和成长占位符需通过完整性校验。
人工审校状态和旧发布例外不会自动扩大。

## 离线与桌面兼容

技能代码与资料独立懒加载，不阻塞其他标签页。
Web 预缓存包含技能代码、五套资料、双语包和全部技能图标。
首次联网并完成缓存后，未访问过的技能图标也可离线使用。
桌面将同一组资料及图标纳入三个独立签名资源包。

旧资源没有技能资料三件套时，程序仍可启动。
技能页提示安装资源，地图及其他标签继续可用。
`data/skills.json`、英文包、中文包任一出现时，必须三件齐全。
恢复完整资源后可以重试，不迁移或清空个人记录。
任务资料沿用相同兼容规则。

## 维护

普通构建只读取本地快照、资料、图标和译文。
更新公开 Wiki 资料时，经代理执行以下顺序：

```sh
WIKI_PROXY=http://127.0.0.1:7890 npm run wiki:fetch:skills
npm run wiki:compile:skills
WIKI_PROXY=http://127.0.0.1:7890 npm run wiki:images:skills
npm run wiki:compile:skills
WIKI_PROXY=http://127.0.0.1:7890 npm run wiki:translate:skills
npm run i18n:compile
node scripts/wiki/audit/audit-references.mjs
node scripts/validate/validate-skills.mjs
npm run build
npm test
npx playwright test
npm run test:e2e:updates
npm run desktop:frontend:build
```

`wiki:translate:skills` 复用任务翻译流程的独立技能缓存。
该维护步骤向翻译服务提交公开 Wiki 文本，不提交个人记录。
原始图标哈希不一致时，必须查证固定上传，不能关闭校验。
新资料须重新经过正式发布的翻译、字体和资料门禁。
本轮产物为本地前端和资源，不等同系统安装或正式发布。
