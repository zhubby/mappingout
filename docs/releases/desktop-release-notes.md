MappingOut Desktop 1.3.1：整理工程结构并加固三平台发布校验。

- 前端按应用编排、功能、公共能力、存储和平台分层；原生工程从 src-tauri 改为 desktop。
- 构建、桌面、校验、Wiki、翻译与资源工具按职责归组。默认路径从模块位置定位，支持从其他工作目录调用。
- 发布聚合器拒绝旧版本安装包、缺失的 macOS 安装盘和缺失签名；校验失败时不生成输出目录。
- 发布下载地址统一为目录地址，末尾缺少斜杠时也能生成正确的程序更新链接。
- 指南、发布说明、验收和截图分别归组；同步更新模块地图与维护入口。

应用标识、生产 origin、更新公钥、资源频道与个人数据库名称不变。个人记录和备份保持 v3，继续接受 v1／v2 备份。地图、资料和字体内容不变，升级复用既有签名资源包。任务和技能保持独立懒加载，角色表单草稿保持应用生命周期。

本版本按用户 2026-11-17 的明确要求发布。资料校订仍未完成：131,779 个中文字段位置待人工复核，2,026 个英文字段待确认 Wiki 来源，1,988 个中文字段有数值／标记待核对项，14,086 个中文字段含未译拉丁词。统计包含重复位置，待核对不等于已确认错误。任务攻略仍有 163 项详细攻略来源缺口和 5 个图源缺口；五处技能正文与成长表冲突保留说明，争议数值不参与筛选。

Friz Quadrata Std 的应用内嵌分发许可仍待补充，字体清单保留未批准状态。本次新发布例外仅绑定 1.3.1、当前资料指纹和上述既有问题，不代表译文已复核或字体授权已取得。结构、来源、资源及哈希校验继续执行。详见仓库 docs/guides/i18n.md、docs/guides/quest-guides.md 和 docs/guides/skills.md。

- Windows x86（32 位）与 x64：安装包复用 WebView2；缺失时由内置引导器联网安装。完全离线安装须预装对应架构的 WebView2，并准备三个资源 ZIP。
- macOS arm64：Apple Silicon，macOS 11 或更新版本；初次安装使用 DMG，app.tar.gz 与 .sig 用于程序更新。
- 完全离线导入：将 resources.json 与其列出的三个 ZIP 放在同一目录，在首次准备界面选择“导入离线资源”。
- 升级前建议导出个人备份；个人记录保存在本机，语言偏好不写入个人备份。

Windows 尚无 Authenticode 发布者证书；macOS 使用 ad-hoc 签名，尚无 Apple Developer ID 签名或公证。程序更新和资源使用独立签名，不能替代系统发布者签名。
