MappingOut 1.3.2：优化首次加载与按需离线缓存，提供双架构容器镜像。

- 首屏使用系统字体，首套资料就绪后在空闲时加载原字体，保持现有字形。
- 地图、任务、日历、技能与护甲资料按访问加载；内容 Worker 完成下载、校验和语言投影，界面显示阶段进度并支持重试。
- 地图进度、任务前置、护甲配方和技能筛选复用查询索引，减少重复计算。
- Web 首次只缓存应用壳和入口，随后缓存实际访问的资源；全量离线由用户手动准备，支持进度、取消和重试。
- 双语响应式布局随入口加载；修复延迟字体加载时的窄屏溢出，补齐 Web favicon 与局域网 HTTP 的校验和角色记录兼容。
- 正式容器镜像支持 linux/amd64 和 linux/arm64，复用 Web 产物。原端口和 origin 下的浏览器个人记录保持。

应用标识、生产 origin、更新公钥、资源频道与个人数据库名称不变。个人记录和备份保持 v3，继续接受 v1／v2 备份。地图、资料和字体内容不变，升级复用既有签名资源包。原字体仍约 26 MB，空闲加载仍会下载。全量 Web 离线资源约 161 MiB，由用户手动启动；局域网 HTTP 支持在线访问，远程离线缓存需要 HTTPS。

本版本按用户 2026-11-19 的明确要求发布。资料校订仍未完成：131,779 个中文字段位置待人工复核，2,026 个英文字段待确认 Wiki 来源，1,988 个中文字段有数值／标记待核对项，14,086 个中文字段含未译拉丁词。统计包含重复位置，待核对不等于已确认错误。任务攻略仍有 163 项详细攻略来源缺口和 5 个图源缺口；五处技能正文与成长表冲突保留说明，争议数值不参与筛选。

Friz Quadrata Std 的应用内嵌分发许可仍待补充，字体清单保留未批准状态。本次新发布例外仅绑定 1.3.2、当前输入指纹和上述既有问题，不代表译文已复核或字体授权已取得。仅新增性能与离线准备界面的双语文本，资料和字体输入未改。结构、来源、资源及哈希校验继续执行。详见仓库 docs/guides/i18n.md、docs/guides/quest-guides.md 和 docs/guides/skills.md。

- Windows x86（32 位）与 x64：安装包复用 WebView2；缺失时由内置引导器联网安装。完全离线安装须预装对应架构的 WebView2，并准备三个资源 ZIP。
- macOS arm64：Apple Silicon，macOS 11 或更新版本；初次安装使用 DMG，app.tar.gz 与 .sig 用于程序更新。
- 完全离线导入：将 resources.json 与其列出的三个 ZIP 放在同一目录，在首次准备界面选择“导入离线资源”。
- 升级前建议导出个人备份；个人记录保存在本机，语言偏好不写入个人备份。

Windows 尚无 Authenticode 发布者证书；macOS 使用 ad-hoc 签名，尚无 Apple Developer ID 签名或公证。程序更新和资源使用独立签名，不能替代系统发布者签名。
