3. 中英文即时切换、偏好保存、双语名称搜索、Friz / LXGW 实际字体加载及离线功能页。
4. 原生备份读写、保留 20 份自动备份、非法路径与内容拒绝。
5. 备份目录不可写时阻止恢复，保留原数据。
6. 恢复预览、确认恢复、恢复前备份。
7. 功能页、重新加载、100% / 150% / 200% 缩放和单实例。
8. 进程重启后角色记录持久化。
