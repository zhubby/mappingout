# 独立资源包实施与验收

> 路径迁移说明：本文保留验收当时的命令与提交事实。当前入口见 [工程结构](../guides/project-structure.md)。
日期：2026-11-16。以下记录开发实现与本地测试包的历史验收。2026-11-17 的正式程序和资源发布另见 [1.3.0 发布验收](desktop-1.3.0-acceptance.md)。

## 已实现

- 三个确定性 ZIP：媒体、资料及中英文语言包、字体；与客户端架构无关。
- 独立资源签名、公钥校验、逐包及逐文件 SHA256、临时解压和原子目录启用。
- GitHub 内容寻址资源 Release、资源集清单及独立签名频道；上传重试与包复用，不修改程序 latest。
- 启动优先使用本地资源，24 小时检查间隔、变化包下载、Range 续传、取消、重试和本地清单导入。
- 会话固定资源版本，新版本重启后启用；保留上一代并回退。程序更新先准备目标版本兼容资源。
- Windows 安装包改为 WebView2 引导器；完全离线安装可预装 WebView2，并导入资源包。
- GitHub 仓库已配置 `MAPPINGOUT_RESOURCE_PRIVATE_KEY` secret；本地私钥位于仓库外，仓库仅含公钥。

## 本轮审查修复

- 将签名频道与 ETag 原子缓存，重启恢复已知待下载资源。覆盖检查间隔内恢复、304 后续传，以及旧状态文件或损坏频道缓存下无条件重新获取。
- 启动未确认时，仅在上一代完整且兼容时回退；首次导入、上一代不兼容时保留当前完整资源，允许反复离线启动并确认。
- 当前会话的启动确认不再竞争后台操作锁；界面遇到忙碌错误时也不触发资源回退。真实进程测试用本地代理阻塞请求，旧包失败、新包通过同一断言。

## 发布边界

本机仅验收 Windows x64；Windows x86 和 macOS arm64 的资源路径及构建流程已接入，但本轮未做对应平台构建或图形验收。GitHub 上实际的资源包上传、跨平台更新安装也尚未验收；发布脚本的重试、复用与失败处理已通过模拟 GitHub CLI 测试。

正式发布检查当前拒绝发布：50,723 个中文字段仍待复核，2,026 个英文字段待 Wiki 来源确认，1,380 个数值／标记复核项，6,591 个中文字段含未译拉丁词，Friz 应用分发许可仍未批准；旧 1.2.0 例外因新增界面文案而指纹过期。此次没有变更许可状态、审校状态或发布例外。后续正式发版必须先处理发布检查，再选择新程序版本；不可覆盖原 1.2.0 资产。
