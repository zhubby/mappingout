# Web 首次加载与离线缓存验收

验收日期：2026-11-19。
范围：本地生产 Web 构建与桌面前端。

## 实施范围

- 首屏使用系统字体。首套资料就绪后，空闲时加载原字体。
- 双语响应式布局随入口加载，避免字体加载改变导航布局。
- 功能资料按访问加载。任务与日历深链不等待地图目录。
- 内容 Worker 下载、校验并投影资料。界面显示阶段进度。
- 读取连续 30 秒无进展时中止。单文件读取上限为五分钟。
- 地图进度、任务前置、护甲配方和技能分面复用查询索引。
- 首次安装只预缓存应用壳、入口 JS/CSS、图标和内容 Worker。
- 已访问资料、图片和懒加载模块进入当前版本缓存。
- 首次接管前已加载的模块也会补缓存。
- 全量离线由用户手动启动。下载并发上限为两个文件。
- 全量准备支持取消、失败重试和跳过已缓存文件。
- 关闭准备弹窗会取消任务。清单下载也支持取消。

启动预缓存包含五个构建文件，未压缩体积为 747580 字节，约 730 KiB。
完整离线清单包含 3728 个文件，未压缩体积约 161.22 MiB。
启动预缓存体积不包含当前功能资料和随后加载的字体。
原字体约 26 MB，空闲加载仍会下载这些字体。

## 验收边界

离线验收使用本机回环地址与真实 Service Worker。
HTTPS 或本机回环地址才能启用 Web 离线缓存。
局域网 HTTP 仍支持在线浏览与个人记录。
浏览器能回收缓存。角色记录仍使用独立 IndexedDB。
本次未测量弱网首屏耗时或目标设备的持续内存占用。
本次未发布镜像、更新线上站点或安装桌面程序。
